          컴포넌트

          저장소 design-system/components/global/에 등록된 공통 컴포넌트를 브랜드 토큰으로 렌더링합니다. 브랜드를 바꾸면 모든 컴포넌트가 그 브랜드의 색과 라운드로 다시 그려집니다.

          dialog

          dialog.css · type: default | conciergeMessage · surface: brandFilled | filled | darkFilled | accentFilled · hasSlot

          Dialog는 사용자에게 메시지를 전달하거나 주요 결정을 요청할 때 사용하는 모달 컴포넌트입니다. 세 영역으로 구성됩니다. 1. Header 타이틀 및 설명 · 2. Content 자유로운 내용 구성 (최대 4개 slot까지 사용 가능) · 3. Action 버튼 그룹 및 예약 버튼. 버튼은 Button 컴포넌트를 그대로 재사용합니다.

          header

          screen.css · part: navigationBar | screenTitleRow | statusBanner

          화면 상단 파츠 3종입니다. navigationBar는 navigationBar-brandFilled-bg 토큰, screenTitleRow는 26px 볼드 타이틀과 소개받기 토글, statusBanner는 bg-statusBanner 토큰의 긴급 배너입니다.

          navigation

          tabbar.css · type: male | female · tone: default | brand | dark · 높이 --tabBar-height(54px)

          하단 내비게이션입니다. type male은 만남보장 · 호감교환 · 보이스톡 · 약속 · 내정보, type female은 컨시어지(아바타) · 만남가능일 · 보이스톡 · 약속 · 내정보 구성입니다. tone에 따라 활성 색이 tabBar-active-fg 또는 브랜드 컬러로 바뀌며, 알림 뱃지와 iOS 홈 인디케이터는 선택 요소입니다.

          tag

          screen.css .verifyTag · brand-presets.css .matchTag · 라운드 --r-tag

          verifyTag는 tag-bg-brand-low 배경에 tag-fg-brand 글자를 쓰는 인증 태그입니다. matchTag는 브랜드마다 표현 자체가 달라지는 유일한 컴포넌트로, 리본 · 캡션 · 라벨 · 필 배지 중 브랜드의 문법을 따릅니다.

          button

          button.css · role: primary | secondary | tertiary | negative · variant: filled | outlined · size: 2xlarge~xsmall

          역할 5종과 사이즈 6종(2xlarge 56 ~ xsmall 28)을 제공합니다. primary는 한 화면 흐름에서 1개만, negative는 outlined variant만 지원합니다. 색은 전부 button 토큰, 라운드는 브랜드 프리셋 --r-btn을 따르고, loading 상태는 스피너가 레이블을 대체합니다.

          디자인 시스템 설명서

          화면 HTML에는 브랜드 고유 값을 쓰지 않습니다. 모든 값은 토큰에서, 모든 형태는 공통 컴포넌트에서 오고, 브랜드 전환은 스위치 한 줄입니다. 플레이그라운드가 그 원리 그대로입니다.

          LAYER 1
          토큰, 값의 원본

          색·서체·간격·라운드를 브랜드별 토큰셋 9종으로 관리합니다. Figma Tokens Studio와 연동되며, 빌드 스크립트가 CSS를 자동 생성합니다. 값 수정은 원본에서만 합니다.

          LAYER 2
          공통 컴포넌트, 레고블록

          버튼, 매칭 카드, 컨시어지 채팅, 달력, 탭바, 다이얼로그. 전 브랜드가 같은 블록으로 조립하므로 레이아웃과 크기는 항상 동일합니다.

          LAYER 3
          브랜드 스위치

          화면에 브랜드 지정 한 줄만 넣으면 라운드, 태그 표현, 컬러가 전환됩니다. 기능 온오프는 기능 매트릭스가 결정합니다.

          근거 화면 수집 규격과 운영

          저장 위치와 이름
          브랜드별 폴더에 순번으로 저장합니다. img/<브랜드>/screen_1.png. 고해상도 원본, 상태바 포함 전체 화면.
          문서 연결 (필수)
          캡처 즉시 해당 브랜드 가이드의 컬러, 고유 패턴, 컴포넌트 표현 항목에 근거 번호를 답니다. 연결되지 않은 스크린샷은 학습에 쓰이지 않습니다.
          활용 루프
          새 화면 완성 시 스크린샷을 골드 스탠다드와 나란히 비교해 위계, 밀도, 디테일 차이 3개를 찾아 고칩니다. 근거 화면이 곧 검수 기준입니다.
          완료 기준
          브랜드당 3~5장, 총 31장 확보 시 9개 브랜드 전체가 문서와 시각 근거의 이중 기반을 갖춥니다. 이후 완성안으로 승격되는 화면이 골드 스탠다드에 계속 축적됩니다.
